# UnrealCode 1.0.4

A calmer workspace with a live stage timeline.

- The consented memory model maintains short, evidence-linked work stages.
  Cached views refresh every three seconds while visible. New meaningful
  activity can trigger analysis at a three-second minimum; idle polling costs
  no inference requests. Local stages remain available without memory.
- Compact is the new spacing default. Cozy keeps the old spacing, independently
  of Cinder Dark, Ice Dark, Flashbang and Follow Windows.
- Work uses four small entries, a faded earlier peek and paged Show all controls.
  Questions, approvals, steering, final answers and actionable failures remain
  visible. Tool Activity still provides complete details and cancellation.
- Container status has one top-right control. The Compact rail prioritizes the
  timeline and makes secondary context expandable.
- Repairs cover observer starvation and cancellation, execution-plan revisions,
  history identities, warning labels, migration backups, offline cache browsing,
  browser/app overlay ownership and generated session titles.

A second hunt repaired malformed-stage recovery, metadata-only plan progress,
slow work polling, disconnected failure state, settled timing and optional cache
repair. Empty approved plans retain inferred stages, and plan/prior-stage text
is redacted before observer analysis. See [the bug-hunt record](https://github.com/MCShotty/UnrealCode/blob/v1.0.4/desktop/BUG_HUNT_1.0.4.md).

## Installation and limitations

The Windows installer is unsigned. Save buffers, settle active tasks, close the
app and install manually. The SHA-256 below identifies this hosted installer;
verify its [GitHub build attestation](https://github.com/MCShotty/UnrealCode/blob/v1.0.4/desktop/VERIFY_RELEASE.md) as well.
Existing settings and history use backed-up migrations. Computer remains
experimental and off by default. Earlier releases and tags are unchanged.

Model stages are evidence-linked interpretations, not verified completion.
The three-second interval can increase memory-model usage during continuous
work; idle polling makes no requests and existing memory limits still apply.
Real native Computer, live populated-memory recovery, fresh-machine installation
and screen-reader acceptance remain separate gates.

See [local acceptance](https://github.com/MCShotty/UnrealCode/blob/v1.0.4/desktop/ACCEPTANCE_1.0.4.md)
for the 571-pass suite, fixture scope, performance and remaining limitations.
The local candidate checksum is historical evidence and differs from hosted
release bytes. Always use this release's installer and manifest together.
