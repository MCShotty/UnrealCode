## Confirmed and fixed

| Issue | Reproduction | Fix and regression |
| --- | --- | --- |
| Integrated specialist memory can remain only in its private bank | Hold a private-bank retention POST, promote the workspace, then finish that POST. Only one save occurred, while metadata incorrectly said the shared record was retained. | Promotion increments the record revision. The old receipt cannot settle the new shared record; the outbox saves it to the shared bank. `hindsight-memory.test.ts`. |
| Queued inference can start after memory is disabled or closed | Delay bridge acquisition, disable memory or close the HTTP broker, then release the bridge. The provider was still called. | Generation checks before dispatch; close invalidates the broker generation. Shutdown also waits for and cleans late bridge startup, and rejects new startup during shutdown. `hindsight-memory.test.ts`, `memory-inference.test.ts`, `memory-lifecycle.test.ts`. |
| A stale observer summary can commit after failure or plan progress | Start analysis, then change the recorded work to failed or update milestones without changing the approved plan revision. The old summary was persisted. | Compare recorded task state and the full plan snapshot before accepting the result. `timeline.test.ts`. |
| Optional memory metadata failure hides factual timeline history | Reject `memory.status` while cached events and task state remain readable. Timeline view rejected entirely. | Return factual evidence with a concise summary-unavailable status. No historical inference is rerun. `timeline.test.ts`. |
| Retention and timeline analysis can separately spend the same memory budget | Give the profile one request, spend it on analysis, then request retention. Both provider calls were accepted. | One serialized reservation checks shared measured request/token totals. Concurrent identical retention requests still use one reservation and one provider call. `memory-lifecycle.test.ts`. |
| A rejected memory edit can make subsequent shutdown fail | Reject correction of a missing document, then stop the service. Shutdown rethrew the already-reported metadata rejection. | Drain the metadata queue without replaying previous action errors from shutdown. The original action remains rejected. `memory-lifecycle.test.ts`. |
