# PDF parsing

Use page-bounded text extraction and search. Keep page numbers, file revision, and extraction method with each selected fact. Preserve reading order uncertainty in multi-column layouts, forms, and tables. Do not infer missing cells from surrounding text. Compare layout-derived tables against the visual page before using them for consequential work. Do not execute PDF scripts or submit forms.
