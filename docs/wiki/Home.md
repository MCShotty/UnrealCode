# UnrealCode

UnrealCode is a Windows app for coding with an AI agent. It uses Electron and React for the interface and Unreal Agent in Docker for coding tools. You bring the model provider. Unreal Engine is not required.

This guide covers **1.0.3**, checked on September 30, 2026.

## Start here

- [Getting started](https://github.com/MCShotty/UnrealCode/wiki/Getting-started): install, verify the download, and open your first project.
- [Projects and Docker](https://github.com/MCShotty/UnrealCode/wiki/Projects-and-Docker): trust, containers, and isolated workspaces.
- [Providers and models](https://github.com/MCShotty/UnrealCode/wiki/Providers-and-models): accounts, local servers, and model selection.
- [Chat and sessions](https://github.com/MCShotty/UnrealCode/wiki/Chat-and-sessions): messages, questions, steering, and history.
